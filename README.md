# 디임팩트학원 수강생 신청이력 조회 & 수납 관리 서비스

대치동 **디임팩트학원**의 수시 논술 파이널 수강생 신청 내역 조회 및 결제선생(Payssam) 수납 관리 시스템입니다.

---

## 🌟 핵심 기능

### 1. 학생/학부모 신청 현황 조회 (`/`)
- 학생 이름 + 전화번호 뒷자리 4자리(결제선생 링크 수신 번호) 입력 조회
- 파이널 강좌(`'#'` 포함 수업)만 깔끔하게 노출
- 파기사유에 `"현장 납부"` 기재 시 자동으로 초록색 `[수납]` 뱃지 반영 (일반 파기건 제외)
- 안내메시지(F열)에 강좌 변경(`기존강좌 → 변경강좌`) 기록이 있을 시 이전 강좌 자동 숨김
- 학원 직통 전화 (`02-6956-0289`) 원클릭 연결

### 2. 관리자/데스크 대시보드 (`/admin`)
- **실시간 통계**: 총 발송건수, 수납건수, 미납건수, 취소/파기건수 및 총액 (결제선생 매니저 사이트와 100% 일치)
- **다운로드 폴더 실시간 자동 감시 (Auto-Watcher)**:
  - 결제선생 매니저 사이트(`manager.payssam.kr/bills`)에서 **[엑셀 다운로드]** 버튼만 누르면, 윈도우 다운로드 폴더의 새 엑셀 파일을 0.5초 만에 자동 감지하여 갱신합니다.
- **수동 엑셀 업로드 (Drag & Drop)**: 엑셀 파일을 브라우저 화면에 끌어다 놓기만 해도 즉시 갱신
- **강좌별 수강생 명단 자동 추출 (가나다순)**:
  - 강좌별(예: `#홍익대 파이널반(A)_이태규T`, `B반` 등) 수납 완료자 명단 자동 정렬
  - **[이름만 복사]**, **[이름+연락처 복사]** 원클릭 지원
- **개강/등원 안내 문자(LMS) 원클릭 생성**:
  - 선택 강좌의 회차별 수업 일정 및 수강생 명단이 결합된 안내 문안 자동 완성 및 원클릭 복사

## 🚀 실행 방법

### 방법 1: `run.bat` 파일 더블클릭 (가장 간편)
프로젝트 폴더 내의 **`run.bat`** 파일을 더블 클릭하면 검은색 콘솔 창이 뜨며 서버가 즉시 실행됩니다.

### 방법 2: 터미널에서 직접 실행
```bash
python server.py
```

- **학생/학부모 조회 페이지**: [http://localhost:8000](http://localhost:8000)
- **관리자 콘솔**: [http://localhost:8000/admin](http://localhost:8000/admin)

## 🔌 결제선생 공식 API 연동 확장 안내
향후 결제선생과 파트너 제휴 계약 체결 및 API Key 발급이 완료되면, `data_manager.py`에 API 호출 모듈을 연결하여 매니저 사이트 방문 없이도 완전한 실시간 클라우드 동기화가 가능하도록 설계되어 있습니다.
