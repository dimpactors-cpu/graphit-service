# 그래프잇 (Graphit) — 온라인 진단검사 및 수강생 신청이력 조회 서비스

기존 그누보드5 / 영카트5 PHP 기반 백업본(`250802/www`) 및 MySQL 덤프(`20240516_slwlab_DB_Backup.sql`)를 **Vercel 배포용 Next.js 풀스택 웹 애플리케이션**으로 완벽히 복원 및 고도화한 프로젝트입니다.

---

## 주요 기능

1. **메인 스토어프론트 및 검사 신청 (`/`, `/shop/item/[it_id]`, `/shop/orderform`)**
   - 메인 배너, 온라인 진단검사 프로그램 목록 및 상세 안내
   - **단체코드 인증 신청** (유효기간 및 잔여 정원 실시간 검증, 무료 신청 처리) 및 일반 결제 신청 지원
2. **온라인 진단검사 응시 시스템 (`/test`, `/test/run`, `/test/result`)**
   - 7개 유의사항 동의 체크 및 이어하기 기능
   - 문항별 제한시간(`item_timer`) 카운트다운 및 시간 초과 시 자동 제출(`5` 또는 `모름`)
   - 객관식(5지선다) / 주관식(500자) 문항 및 이미지(`/data/test/*`) 렌더링
3. **3단계 회원 권한 체계 및 마이페이지 (`/mypage`)**
   - **개인회원 (`mb_level = 2`)**: 본인이 신청한 검사 내역, 실시간 진행률 바, `시작하기` / `이어서하기` / `검사완료`, 구매 상세 내역 조회
   - **단체회원 (`mb_level = 3`)**: `단체관리페이지` 대시보드, 보유 단체코드 선택, 배정 정원 대비 `미등록 / 시작전 / 진행중 / 검사완료` 인원 집계 및 `#상세진행현황` 수강생 실시간 테이블
   - **최고관리자 (`mb_level = 10`)**: 전체 관리자 센터(`/adm`) 및 통합 엑셀 다운로드(`.xls`)
4. **관리자 센터 (`/adm`)**
   - **대시보드 (`/adm`)**: 전체/오늘 가입 및 검사 통계, 5종 통합 엑셀 다운로드 센터
   - **수강생 검사현황 (`/adm/tests`)**: 단체코드·검사별 필터링, 진행률 조회, **수강생 문항별 상세 응답 모달**
   - **개인회원 관리 (`/adm/members/personal`)**: 수강생 정보 수정 및 신청/주문 이력 조회
   - **단체관리 및 단체코드 발급 (`/adm/members/groups`)**: 신규 단체 등록, 단체코드 발급/삭제, 코드별 수강생 진행현황 조회
   - **문항관리 (`/adm/questions`)**: 272개+ 객관식/주관식 문항 등록·수정·삭제
   - **검사관리 (`/adm/checkups`)**: 검사 프로그램 설정, 출제 문항 매핑, 노출순서(`item_seq`) 및 제한시간(`item_timer`) 일괄 수정
   - **클라우드 DB 연동 (`/adm/db-sync`)**: Supabase / Neon PostgreSQL 원클릭 테이블 생성 및 백업 데이터 동기화

## 실행 및 Vercel 배포 방법

### 1. 로컬 실행
```bash
npm install
npm run dev
```
브라우저에서 `http://localhost:3000` 접속

### 2. 클라우드 DB (Supabase / Neon PostgreSQL) 연동 (선택사항)
- 기본적으로 `src/data/seed-db.json`에 `20240516_slwlab_DB_Backup.sql`의 모든 데이터(회원 208명, 문항 272개, 검사신청 224건, 문항응답 25,446건 등)가 내장되어 있어 **별도 DB 설정 없이도 즉시 동작**합니다.
- Vercel 배포 환경에서 영구적인 클라우드 DB 저장을 원할 경우:
  1. Supabase 또는 Neon에서 PostgreSQL 프로젝트를 생성합니다.
  2. Vercel 프로젝트 설정의 **Environment Variables** (또는 로컬 `.env.local`)에 `DATABASE_URL`을 등록합니다.
  3. 최고관리자(`admin`)로 로그인 후 **`/adm/db-sync` (클라우드 DB 연동)** 메뉴에서 **[클라우드 DB 테이블 생성 및 전체 데이터 동기화 실행]** 버튼을 클릭하거나 아래 명령어를 실행합니다:
     ```bash
     npm run db:sync
     ```
